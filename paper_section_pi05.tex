\subsection{A second backbone: \meci on the flow-matching action expert of \texorpdfstring{$\pi_{0.5}$}{pi0.5}}
\label{sec:pi05}

To test whether the interface depends on OpenVLA-OFT's deterministic regression head, we also attach \meci to $\pi_{0.5}$~\citep{intelligence2025pi05}, using the open-source \texttt{openpi} implementation (commit \texttt{215abfb}). $\pi_{0.5}$, like $\pi_0$~\citep{black2024pi0}, pairs a PaliGemma vision-language backbone with a smaller \emph{action expert} (a 300M-parameter Gemma variant, width $w{=}1024$, 18 layers) that produces an action chunk $A\in\R^{H\times 32}$ by flow matching~\citep{lipman2023flowmatching}. The expert reads the backbone's key-value cache and integrates a learned velocity field $v_\theta(A^\tau, o, \elltask, \tau)$ from noise ($\tau{=}1$) to actions ($\tau{=}0$) with ten Euler steps. Unlike $\pi_0$, $\pi_{0.5}$ does not add the flow time to the action tokens; it injects it into every expert layer through adaptive RMS normalization (adaRMS), whose zero-initialized projection yields a per-layer scale, shift and residual gate, in the spirit of adaLN-Zero~\citep{peebles2023dit}. This gives a natural, layer-wide conditioning channel that OpenVLA-OFT lacks.

\paragraph{Where the correction enters.}
The utterance is encoded exactly as in Section~\ref{sec:audio}: frozen Whisper-small features~\citep{radford2023whisper} are compressed by $Q{=}16$ learned queries~\citep{jaegle2021perceiver} into correction tokens $c\in\R^{Q\times w}$ in the expert's width, a zero-initialized displacement head predicts $\widehat{\delta p}\in\R^6$ and effector logits, and zero-initialized embeddings of the (parsed or predicted) $\delta p$ and effector $e$ are added to $c$. Let $x_i$ be the expert's input token for chunk step $i$, $t_\tau$ the adaRMS time embedding, $h_i$ the expert's last hidden state, and $s_t\in[0,1]$ the hold-and-fade strength ($s_t{=}0$ when no correction is active). \meci adds three gated paths, each scaled by $\tanh(g_\cdot)$ with $g_\cdot$ initialized to $0$~\citep{alayrac2022flamingo,zhang2023controlnet}:
\begin{equation}
\begin{aligned}
  x_i' &= x_i + \tanh(g_{\mathrm{in}})\, s_t\, \mathrm{XAttn}_{\mathrm{in}}(x_i, c),\\
  t_\tau' &= t_\tau + \tanh(g_{\mathrm{ada}})\, s_t\, W_{\mathrm{ada}}\,\bar c,\\
  h_i' &= h_i + \tanh(g_{\mathrm{head}})\, s_t\, \mathrm{XAttn}_{\mathrm{head}}(h_i, c),
\end{aligned}
\label{eq:pi05-fusion}
\end{equation}
where $\bar c$ is the token mean and $v_\theta$ is read out from $h'$ by the unchanged output projection. The first path conditions the action tokens before all 18 expert layers, the second reaches every layer through adaRMS, and the third mirrors the OpenVLA-OFT fusion point just before the read-out. With $g_\cdot{=}0$ or $s_t{=}0$ the three equations are exact identities, so the patched model reproduces the pretrained checkpoint bit for bit; we verify this against unmodified \texttt{openpi} on CPU with a reduced-size model. As an ablation, $c$ can instead be appended as $Q$ extra expert tokens that the action tokens attend to; their attention mask is switched off when no correction is active, which leaves token positions and outputs unchanged, but unlike~\eqref{eq:pi05-fusion} this variant is not an identity at initialization while a correction is active.

\paragraph{Explicit residual and named effectors.}
Because flow matching samples rather than regresses, the commanded displacement is also enforced explicitly. The parsed $(e, \delta p)$ is mapped to the platform's raw action space, distributed over the hold window, normalized with the checkpoint statistics, and added to the sampled chunk: $A \leftarrow A^{0} + r$. $\pi_{0.5}$ normalizes actions with per-dimension quantiles, $\hat a = 2(a-q_{01})/(q_{99}-q_{01}) - 1$, so an additive raw residual $\Delta a$ maps exactly to $2\Delta a/(q_{99}-q_{01})$. The mapping depends on the action layout, which we read from \texttt{openpi}. On LIBERO~\citep{liu2023libero} the first six dimensions are per-step end-effector deltas for robosuite's operational-space controller~\citep{zhu2020robosuite}, with one unit of action commanding $0.05$\,m or $0.5$\,rad, so the per-step residuals are scaled and sum to $\delta p$. On bimanual ALOHA~\citep{zhao2023aloha} the 14-D action is $[\text{left joints}(6), \text{left gripper}, \text{right joints}(6), \text{right gripper}]$ in \emph{joint} space, expressed relative to the joint state at the start of the chunk. There, $\delta p$ for the named arm is converted by a damped-least-squares step $\Delta q = J_e^\top (J_e J_e^\top + \lambda^2 I)^{-1}\delta p$ with that arm's Jacobian $J_e$, written only into that arm's slice, and applied as a ramp whose final value is $\Delta q$. An unnamed correction on a bimanual robot is not routed to either arm. DROID~\citep{khazatsky2024droid} is likewise joint-space. During training, the flow is fit to the executed chunk minus this residual, so the sampled chunk plus the residual reproduces the executed actions.

\paragraph{Training and RL.}
The \emph{follow} objective is $\pi_{0.5}$'s own flow-matching loss on during-correction chunks~\eqref{eq:seg-dur}, with the correction tokens attached, plus the auxiliary loss $\lambda_{\delta p}\lVert\widehat{\delta p}-\delta p\rVert_1$ and an effector cross-entropy. Flow matching has no tractable action log-likelihood, so the Laplace reading used for OpenVLA-OFT does not carry over. For the \emph{autonomous} pass we use two likelihood-free analogues: advantage-weighted flow matching~\citep{peng2019awr}, which multiplies the per-sample flow-matching loss by $\min(\exp(\adv/\beta), w_{\max})$ as in~\eqref{eq:awr}, and a Diffusion-DPO-style preference loss~\citep{wallace2024diffusiondpo} that replaces the log-likelihood ratios in~\eqref{eq:dpo} with differences of flow-matching errors against a frozen reference, computed with shared noise and time. Here the during-correction chunk is preferred over the pre-correction chunk from the same state. Online RL with tractable likelihoods is possible through $\pi_{\mathrm{RL}}$~\citep{chen2025pirl}, which either models denoising as a discrete-time MDP with a learnable noise network for exact log-likelihoods (Flow-Noise) or converts the ODE sampler into an SDE inside a two-layer MDP for exploration (Flow-SDE), and fine-tunes flow-based VLAs such as $\pi_0$ and $\pi_{0.5}$ online. Using it to fine-tune \meci policies from correction-derived rewards is future work.
